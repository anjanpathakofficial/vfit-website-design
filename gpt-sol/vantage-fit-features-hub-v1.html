The through-line

One log, one set of program rules.

Vantage Fit does not split movement, daily habits, and guided wellbeing into separate participation programs. Eligible employee activity reaches the same challenges, then rolls up to an aggregate view HR can use.

Log

Employees record the day

Phone steps, GPS workouts, daily habits, guided minutes, and health inputs begin in one mobile experience.

Count

Challenges apply the rules

Eligible logs meet the same task and challenge rules, so participation does not split into program silos.

Review

HR reads the aggregate

Reporting shows whether the program is being used without opening an employee's private health record.

All features

Scan what is included, then open the detail.

The badge on each card is part of the specification. It shows what a Full-Mode admin can use directly, what needs an annual agreement or partner setup, and what disappears in Lite Mode.

Platform reality: iOS and Android carry the full employee experience. Web supports steps, limited manual logging, and the admin dashboard. The lab-report web upload exception is marked on its card.
