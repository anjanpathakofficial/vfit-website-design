The setup every format shares.

Whichever format you pick, the same six fields follow it to publish.

  • Name, description, bannerWhat employees see on the card.
  • Start and end datesLocalised, so daily targets reset at local midnight.
  • Privacy and target audienceApply any filter and the challenge turns private.
  • Teams and maximum team sizeThe average of member scores, never the sum.
  • Point rewardsPer task, per milestone or for final standings.
  • CertificateLogo, seal, signature, signer name and designation.

Before your first build

How long does the first challenge actually take?

A Race from a template is minutes: name, dates, audience, publish. A multi-week Custom takes longer, because you write the weekly themes as well as the targets.

Does anyone need a wearable?

No format requires one. Steps come from the phone or a connected device, and everything else is logged in the app.

Can I change a challenge after it starts?

Yes. Edit details, add a theme for a week that has not begun, add or remove participants, reschedule, force start, or stop it early.
