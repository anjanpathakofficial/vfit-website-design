Anti-cheat

What gets a workout thrown out.

A leaderboard is only worth running if a car ride cannot win it.

On iOS

Any location point below 100 m horizontal accuracy is discarded before the route is drawn.

On Android

A four-method vehicle check reads speed patterns, location consistency, the share of high-pace samples, and split analysis. A point needs 10 m and one second of gap to be kept.

On the server

A run or walk averaging faster than 3.5 min/km is rejected, and every split has to clear the same bar.

There is no pace limit on cycling.

A real cyclist clears the running threshold, so applying it would throw out legitimate rides. Cycling still goes through accuracy filtering and the vehicle check. We would rather print the gap than claim a test we do not run.

Workout import Manual tap on iOS
On iPhone, Apple Health surfaces the workout and a notification appears. The employee taps Import. Never automatic. On Android, workout import runs through Health Connect. Running, walking, cycling and wheelchair arrive with distance, duration, calories, route and splits.

Rollout questions

Three things buyers ask in week one.

Everything on this page is Full Mode. Lite Mode is steps only, so none of it appears.
Does any of this need a wearable?

No. GPS workouts, the squat tracker and strength logging all run on the phone. A wearable adds workout import and better step accuracy.

A Garmin stopped syncing after two months. Why?

Garmin access tokens expire at 60 days. Reconnect from Settings, Device Management, and a manual sync backfills the last seven days.

Can someone import a swim from an Apple Watch?

Not today. Import covers running, walking, cycling and wheelchair. A swim is still loggable by hand as one of the 65 activity types.
