# Multi-activity (Custom) Challenge — consolidation decisions

Consolidated best-of from the 4-model bake-off (Claude Fable, Kimi K3, GPT-Sol, Grok).

## Base
- **Structure core = GPT-Sol** (team preference): hero "One challenge. More ways to take part." → "A single metric is not everyone's way in" → "Plan a story, not a pile of tasks" (weekly themes) → 27 task types → "Start with a template. Make it yours. Run it from one place." (HR) → customer → FAQ → closer.
- **Copy upgrades grafted in:**
  - **Grok** — real **named customer proof** (Brazosport, Wipro, Intrado) and a sharper FAQ.
  - **Kimi** — problem framing ("step-only races leave most of the company out").

## Design
- Our Poppins consolidated system (same as Steps + Team pages). New page-specific visuals: the **4-week theme strip** (Move/Nourish/Reset/Thrive) and GPT-Sol's **filterable 27-task explorer** — category tabs (All / Movement / Workouts / Mind and body / Nutrition / Health / Learning / Habits) over a card per task, filtered client-side. (Chosen over an earlier 7-category-card grouping to match GPT-Sol's original layout.)

## Copy length
- Supporting copy under the headings was trimmed ~26% per stakeholder feedback ("keep less text in the subsections"). Headings, FAQ answers, and the answer-first definition were kept intact for SEO/AEO.

## SEO / AEO
- Title: "Employee Wellness Challenge Platform & Ideas | Vantage Fit"; slug `/solutions/wellness-challenge`; primary keyword `employee / corporate wellness challenge` (per SEO brief — likely a pillar-level page).
- Answer-first "What is a multi-activity wellness challenge?" folded in as the first FAQ item (also in FAQPage schema). 3 JSON-LD blocks (FAQPage + SoftwareApplication + BreadcrumbList), meta/canonical/OG, one H1, query-matched H2s, internal links.

## Accuracy
- Custom Challenge = self-serve, multi-week, up to 27 task types; balanced scoring (non-step tasks stop at 100% of target; steps daily cap default 25,000); Full Mode = all 27, Lite Mode = steps only; optional teams average member scores; personal health data (weight/HRA/lab/mood/food/sleep) never visible to admins; local time-zone windows; HIPAA/SOC2/GDPR/ISO.
- Real proof: **Brazosport ISD Fit Wars 86%** and **Wipro 3×** are approved. **Intrado Healthy Me 1,100+** carries a VERIFY comment — confirm before publishing.
